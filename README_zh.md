## 为什么是 Gloss？

日常 Review 别人（或者 AI 助手）写的大量改动代码时，最痛苦的不是看 diff，而是**看不懂这几行具体在解决什么、意图是什么、有没有暗坑**。

Gloss 是一款专注于**高效代码阅读与安全 Git 操作**的跨平台客户端（macOS / Linux / Windows）：
- **提交前把风险挑出来**：一键预检暂存区的全部改动，AI 按严重度列出硬编码密钥、注入风险这类可疑点，每条都指到文件和行号。
- **纯粹的原生极速**：用 [mygo](https://github.com/egoist/mygo) 编写，GPU 直接绘制，**没有 webview、没有 JS 运行时、单个二进制文件**，启动如闪电，滚动丝滑，内存占用极低。

## 核心特性

- ⚡ **原生 GPU 直绘**：零 Web 框架开销，极低内存占用，对齐 GitHub 视觉美学与各平台原生体验。
- 🛡 **变更预检**：一键扫一遍暂存区的全量改动，可疑处按严重度归类，每条指到文件与行号；没问题就报「安全通过」。
- 🤖 **AI 提交信息与分支名**：按 Conventional Commits 从暂存改动生成提交信息（可附一句意图提示），也能按一句话描述起分支名。
- 🌲 **Fork 式上下分 & 拓扑图**：自研提交拓扑图，直观梳理分支合并脉络；配色三套内置方案（经典 / 鲜艳 / 灰阶）可切换，深浅两套还能逐号微调；下半区分立文件树与详细 diff。
- 🔍 **Viewed 联动折叠**：标记已 review 的文件在 diff 中自动折叠，一屏扫完未审阅代码，文件变动标记自动失效。
- 🛠 **硬核 Git 工作流**：
  - **暂存与提交**：支持文件级暂存与**按块暂存（Hunk Staging）**、保留草稿、修改上次提交（`--amend`）。
  - **分支与远程**：一键切换/新建/重命名/删除分支，安全合并与变基，带 `--force-with-lease` 租约保护的强制推送。
  - **储藏管理（Stash）**：清晰查看储藏改动 diff，安全应用（Apply）、取出（Pop）与带确认的丢弃（Drop）。
- 🦺 **错误与冲突全说人话**：
  - 拒绝冷冰冰的 git 报错：钩子拦截、锁文件、凭证异常皆有人话指引与解决建议，保留原话备查。
  - 变基/合并冲突时弹出醒目琥珀色状态条，支持文件逐个双向挑边、智能提示删除变更、安全中止二次确认。
- ⌨️ **全键盘流 & 全局命令栏**：`⌘K` 调出命令栏，`J` / `K` 快捷跳转改动块，常用操作全局快捷键覆盖。
- 🤖 **全模型兼容**：内置 Anthropic / DeepSeek / Kimi(Moonshot) / 通义千问 / 智谱 GLM / OpenRouter / Ollama 预设，兼容任何 OpenAI 兼容端点。

## 功能详述

- **本地 git 仓库**：打开一个工作副本，看未提交的改动；侧栏列着分支 / 远程 / 标签 / 储藏，点一条分支就只看它的历史，点一条储藏直接看它的改动。
- **暂存与提交**：文件行左边的方框按整个文件暂存，hunk 头上的按钮按块暂存 —— 改动因此分成「已暂存 / 未暂存」两段，同一个文件可以两边各占一份；提交栏里写信息（`⌘⏎` 提交），写了一半的消息按仓库记着，切走再回来还在。
- **编辑器视图列的是整个工作区**：编辑器那栏的左栏列的是工作区里的全部文件（`git ls-files`：已跟踪，加上没被 `.gitignore` 忽略的未跟踪文件），不是只有改动过的那几个 —— 工作区没有改动也照样列。改动过的文件保留状态字母、暂存框与行号旁的改动标记，没改过的文件干干净净地打开；这一栏有自己的筛选词和选中下标，切视图来回不会互相串。栏脚报的是「工作区里改过几个文件」—— 从改动列表切过来时丢掉的就是这条信息。
- **删分支是两个动作**：删本地分支（右键本地分支 →「删除分支 x…」，先确认一次，没合并再问第二次）和删远程分支（右键远程分支 →「删除远程分支 x…」，单独的确认框，写明本地分支不动）是分开的两件事。有上游的本地分支上也顺手摆着「删除远程分支 origin/x…」—— 删的仍然是远程那份，本地留着。
- **文件行右键菜单**：改动 / 历史 / 储藏三个视图里的文件行都能右键 —— 暂存 / 取消暂存（冲突文件换成「用我们的 / 用他们的」加「标记为已解决」）、丢弃更改…（未跟踪的文件写的是「删除这个文件…」，两种都先问一句再动手）、在编辑器打开、在访达中显示、复制路径 / 复制相对路径 / 复制文件名、查看文件历史…、标记为已查看 / 取消已查看、加入 .gitignore。历史提交和储藏里的文件行是只读的：那几项会动工作区的动作在那里不出现。
- **查看文件历史…**：列出这个文件自己的提交（`git log --follow`，改名之前的也跟得住），点一条就切到历史 tab 并选中那次提交去看 diff —— 不用在整条分支的历史里翻它在哪几次里出现过。
- **切分支 / 检出 / 打标签**：侧栏里的分支和标签双击就是检出，右键菜单也可以（菜单文案会把去向写全：「检出标签 v1（分离 HEAD）」）；远程分支会顺便建一条本地分支并设好上游，本地已有同名分支时降级为切过去。检出标签之后工具栏那枚分支芯片换成警示色 —— 分离 HEAD 上提交会成为游离提交，得先说出来。
- **分支集成与远程管理**：
  - 本地分支右键：支持「把 `<分支>` 合并进当前分支」与「把当前分支变基到 `<分支>`…」（变基会改写提交历史，执行前带风险说明二次确认；若遇冲突自动切入琥珀色 PendingBar 解决）。
  - 远程分支右键：支持直接检出跟踪分支，或通过「删除远程分支 `<remote>/<name>`…」从远端安全删除分支（带确认弹窗与人话错误翻译）。
  - 标签右键：一键推送到远程 `origin`。
  - 远程菜单与命令栏：新增「强制推送（--force-with-lease）…」，仅在当前分支配有上游且非分离 HEAD 时可用，弹窗确认提示 `--force-with-lease` 租约保护机制，安全防止冲掉协作者的新提交。
- **打标签**：历史里右键一个提交 → 名称 + 说明（附注标签）或只给名字（轻量标签）。重名、名字非法这些错误留在对话框里，名字和说明一个字都不丢。
- **储藏管理与修改上次提交**：
  - **储藏（Stash）**：菜单「文件 → 储藏工作区改动…」或命令栏唤起模态对话框，支持备注说明与是否包含未跟踪文件（`-u`）；干净工作区保存时人话阻断提示；侧栏储藏分组单击查看完整 diff，右键支持应用（Apply）、取出并丢弃（Pop）、丢弃（Drop，带二次确认与说明回显）、复制储藏名。
  - **修改上次提交（Amend）**：提交栏常驻「修改上次提交」复选框，开启后自动拉取并预填上一次提交信息，支持零暂存改动下纯改提交信息，或合并新暂存改动至上次提交。
- **远程：抓取 / 拉取 / 推送**：工具栏三颗图标 —— 抓取只更新远程分支、不动工作区；拉取把远程的提交合进来；推送发出去，第一次推会自动建好上游（`-u origin <分支>`）。仓库没有远程时这三颗根本不画（`git fetch --all` 在没有远程时是**静默成功**的，灰按钮等不到任何解释）；分离 HEAD 上拉取和推送变灰，悬停会说清为什么。失败照样说人话：推送被拒、分支分叉、连不上、要登录各有各的说法 —— 我们没有凭证输入 UI，凭据类失败会明确指向「在终端里登录一次」。
- **改动区一次看一个文件**：左边文件列表导航，右边是 mygo 的 DiffView —— 红增绿删、双侧行号、词级内联高亮、未改动区间折叠、语法高亮都归它；未暂存段的右侧可以直接改（改完保存只写工作区，不替你暂存）。
- **变更预检**：提交栏里的「🛡️ 变更预检」把暂存区的全量 diff 交给模型扫一遍，硬编码密钥、注入风险这类可疑处按严重度（严重 / 高危 / 中危 / 低危）列进一份报告，每条带文件与行号。失败时不甩一坨 HTTP 错误：说清是什么事、怎么办（密钥不对直接给一条「模型设置…」），供应商的原话留着可查。
- **AI 提交信息与分支名**：提交栏的 AI 按钮按 Conventional Commits 生成提交信息，输入框里的备注会当作意图提示一起喂给模型，旁边的中/英按钮决定生成语言；新建分支对话框里可以按一句话描述生成分支名。
- **Fork 式的上下分**：主区上半是提交列表（左边一条自己算的提交拓扑图），下半左边是文件列表、右边是选中提交里某一个文件的 diff；点文件列表里的一行，右边就换成那个文件。
- **文件树**：可折叠的目录树（只含一个子目录的目录链合并成一行）、模糊筛选（`⌘P`）、每行右侧 `+N −N` 和状态字母、底部一条常驻栏脚写着总计和已 review 进度。
- **在改动里查找（`⌘F`）**：查找栏归 DiffView 自己（焦点在改动区里时 ⌘F 打开），边打边高亮、`⌘G` / `⇧⌘G` 在命中间来回走。内容查找和文件查找是两条路：`⌘F` 找内容、`⌘P` 找文件。
- **按段暂存**：鼠标停在改动上（或光标落在上面）就会出现「暂存这段 / 取消暂存这段」—— 段是 DiffView 按两侧原文划的，点一下只把这一段放进（或撤出）index，同一个文件别的那几段留在原地。
- **Viewed 标记**：标了 `已 review` 的文件在文件列表里变淡、勾亮起；内容一变标记自动失效。
- **写操作说人话**：暂存 / 提交失败时顶上一条横幅 —— 出了什么事、能怎么办、git 自己的原话（钩子拦下、`index.lock`、没配 user.name、GPG 签名失败……都有对应的说法），原话永远留着可查。
- **停在冲突里也有出路**：合并 / 变基 / 拣选 / 回退 / 补丁序列停在半路时，顶上一条琥珀色状态条 —— 还剩几个冲突文件、接着「继续」还是「跳过」，不做了就「中止」（会先把「已经解决的部分也要重来一次」说清，问一句再动手）。它和红色的失败横幅分开伺候：横幅说的是「刚才那一下出了什么事」，读完自己关掉；状态条说的是「仓库现在什么状态」，事情没了结它不消失。变基期间工具栏的分支芯片改口报「正在变基 topic → main（第 1/2 步）」而不是喊「分离 HEAD」；储藏 apply/pop 撞出来的冲突没有可继续的步骤，状态条只叙述、不摆按了会落空的按钮。
- **冲突文件在改动区里直接解决**：选中冲突文件，右边就是带着 `<<<<<<<` 标记的那一份正文（左侧可以切「当前分支 / 对方 / 共同祖先」），每一处冲突底下都有「留下 X / 留下 Y / 两个都留 / 都不要」；顶上那条给整文件的三条出路（全部用某一边、在编辑器打开），右侧也可以自己改，改完「保存并标记已解决」一次写完盘 + `git add`。变基里两边是反的，按钮按变基的说法写（「用变基目标的 / 用重放中的」），对方删了文件时会**提前说明「这一按是接受删除」**；文件行右键同样能挑边，栏脚数着还剩几个。
- **命令栏（`⌘K`）**：所有功能都能键盘调到。
- **多供应商配置**：内置 Anthropic / DeepSeek / Kimi(Moonshot) / 通义千问 / 智谱 GLM / OpenRouter / Ollama 预设，任何 OpenAI 兼容接口都可用；也支持 `ANTHROPIC_API_KEY` 环境变量回退。左栏只摆已添加的供应商，行首手柄可以拖动排序（排序跟着「保存」走，点取消就作废）；加新的从「添加供应商」按钮的菜单里挑，已经在列表里的那几家在菜单里灰着。
- **Git 配置**：设置里的「Git 配置」一页看全三层 —— 全局（`~/.gitconfig`，这台机器上你的每个仓库都吃它）、当前项目（`.git/config`，只此一个仓库）、系统级（`/etc/gitconfig` 这类厂商 / 机器级文件，只读摆出来）。这一页只回答一个问题 —— **提交时 git 认为你是谁** —— 所以只管 `user.name` / `user.email` 这两项。分支、远程、`core.*` 这些结构性配置不在这一页：它们在各自的面板里有正经入口，摊在这里当普通键值改，改错了不容易看出来。项目级那份可以**跟随全局**（保存时把 `.git/config` 里这两项删掉，让全局那份生效），也可以**单独设置**（只作用于这个仓库）；把某一项清空的意思是「这一层不再设它」，会把键删掉而不是写成空值，输入框的提示文字就是清空之后会用上的那个值。**保存时只写动过的行** —— 配置文件里的注释、`include` 顺序、Gloss 读不懂的写法都原样留着，不做整份重写；读写都走命令行 git，所以 `includeIf` 条件、子节这些在命令行里怎么生效，这里就是怎么生效。零配置也能用：提交失败里那句「还没配 git 用户名和邮箱」现在先把你引到这一页。
- **状态持久化**：已 review 标记、提交草稿、窗口设置都存在 `~/Library/Application Support/Gloss/`。

| `⌘⏎` | 提交（输入框里回车是换行，所以带 `⌘`） |
| `⌘O` | 打开仓库 |
| `⌘1` / `⌘2` | 改动 / 历史 |
| `⌘⇧B` | 收起 / 展开侧栏 |

> 菜单栏（`menu.go`）里每一项都带着同一个快捷键：真实 macOS 应用里原生菜单会先把键吃掉，视图那条路走不到，两处的按键映射保持一致。

## 构建与运行

需要 **Go 1.27+**（mygo 的硬要求，`mise.toml` 里已经预设好）。

```bash
# 1. 安装指定版本环境
mise install                 # 装 Go 1.27.1

# 2. 本地开发调试（改动自动重载）
go tool mygo dev             # 开发模式，改完自动重启

# 3. 生产打包
go tool mygo build           # 出 .app 和 .dmg（build/darwin-arm64/）

# 4. 自动化测试
go test ./...                # 界面是无头的，测试不需要物理开窗口
```

### Windows：Defender 报安装包是误报

Windows Defender 的 ML 启发式（通常显示为 `Trojan:Script/Wacatac.C!ml`）会报 `Gloss.Setup.<版本>.amd64.exe`。这是**误报**：构建不压缩、不混淆，安装时也不下载执行任何东西；未签名、每个版本又是全新哈希的安装包，恰好是这套启发式打分最低的画像。

**被拦住时两条路：**

1. **不用安装**。下 `gloss-<版本>-windows-amd64-portable.zip`，解压后直接跑 `Gloss.exe`。它和安装包装下去的那份是同一个构建（同一个 `Gloss.exe` 和 `ghostty-vt.dll`），不需要管理员权限，也不在自身目录之外写东西。
2. **放行**。Defender →「保护历史记录」→ 找到这条 →「操作」→「允许在设备上」，或把下载目录加进排除项。

**提交误报**：检测是按文件哈希记的，所以每个新版本都会被重新报一次 —— 每发一版交一次，通常几小时内清掉：<https://www.microsoft.com/en-us/wdsi/filesubmission> →「软件开发者」→ 上传被拦的 `Gloss.Setup.<版本>.amd64.exe` →「被错误检测为恶意软件」。微软清掉这个哈希，并把结果回灌给模型。

根治靠代码签名：签过名的包带发行者身份，同样的字节就不再按「匿名二进制」被打分。

## 配置模型

界面右上角「模型设置…」里添加一个供应商即可。API key 保存在 `~/Library/Application Support/Gloss/config.json`（权限 0600）。

若未在 UI 中配置，会自动回退读取环境变量：

```bash
export ANTHROPIC_API_KEY=sk-ant-...
# 可选：export ANTHROPIC_MODEL=claude-sonnet-5-5
# 可选：export ANTHROPIC_BASE_URL=https://...   # 中转/代理地址
```

## 源码架构

```
main.go / app.go         窗口、菜单、app 状态、每帧的根布局
  sidebar.go             侧栏：分支 / 远程 / 标签 / 储藏树
  branchops.go           分支与远程操作：合并、变基、删除分支、删除远程分支、推送标签、强制推送
  renamebranchdialog.go  重命名分支（名称体检与当前分支更新）
  stashdialog.go         储藏对话框（保存未提交改动至储藏栈）
  stashops.go            储藏操作：应用、取出、丢弃确认
  history.go             上半区：提交列表 + 列头
  commitops.go           提交行右键：拣选 / 回退 / 检出（分离 HEAD）/ 复制哈希
  resetdialog.go         重置当前分支（软·混合·硬三档说明 + 丢弃改动告警）
  newbranchdialog.go     从选定提交建分支（名称体检 + 可选建好就切过去）
  graph.go               提交拓扑图：布局（buildGraph）与逐行绘制
  filepane.go            下半区左边：文件列表（含暂存勾选框）
  workspace.go           编辑器视图左栏：整个工作区的文件，而不是只有改动
  filemenu.go            文件行右键菜单：暂存 / 丢弃 / 复制 / 文件历史 / 忽略
  filehist.go            「查看文件历史…」弹窗：这个文件自己的提交，点一条跳去历史 tab
  review.go              改动区：单文件 DiffView（两侧原文、按段暂存、冲突挑边）
  conflict_region.go     工作区文本里的冲突标记解析与按块替换
  files.go               文件列表的标识（fileKey / pathOf / displayPath）
  commitbox.go           暂存勾选框、hunk 暂存按钮、提交栏（含修改上次提交）
  checkout.go            检出：右键菜单文案、双击、检出后的收尾
  tagdialog.go           打标签对话框（名称 / 附注 / 说明）
  remote.go              远程：工具栏那三颗图标、抓取 / 拉取 / 推送的入口
  opbanner.go            写操作的结果：失败横幅 / 成功 Toast
  pendingbar.go          卡在冲突里的琥珀状态条：继续 / 跳过 / 中止
  confirmdialog.go       动手前先问一句（中止合并这类不可逆操作）
  resolve.go             冲突文件逐个解决：挑边的按钮文案、卡片（右键菜单在 filemenu.go）
  treeview.go            两棵树共用的行画法（缩进 / 箭头 / 选中胶囊）
  refs.go                引用树的分组与筛选
  palette.go / keys.go   命令栏、快捷键
  menu.go                菜单栏：同样那批命令，键和 keys.go 一一对应
  settings.go            设置对话框（侧栏 + 通用偏好 / 模型 / 提示词 / 更新 / 关于）
  gitconfig.go           设置里的「Git 配置」页：三层配置的读、改、存（写盘在 internal/gitrepo/config.go）
  theme.go               配色（对齐 GitHub 那套）

internal/
  gitrepo/               git CLI 封装（status / diff / log / refs / 写操作）
    write.go             暂存、按块暂存（hunk ID 与行区间两条路）、提交与修改上次提交（--amend）
    shellpath_*.go       子进程要用的 PATH：GUI 启动时向登录 shell 问一次（带超时与降级）
    range.go             按行区间生成补丁并 apply（DiffView 划出的那一段）

    stash.go             储藏操作（push / apply / pop / drop）
    commitops.go         拣选、回退、重置（--soft / --mixed / --hard）
    branch.go            新建、重命名、删除分支、合并（--no-edit）、变基
    remote.go            抓取 / 拉取 / 推送（含 --force-with-lease、push tag、delete remote branch）
    pending.go           探测停在哪种操作中间 + 继续 / 跳过 / 中止
    conflict.go          冲突文件挑边（ours/theirs、删除-修改走 rm）+ stage 探测
    failure.go           把 git 的错误翻成人话（说什么事 / 怎么办 / 原话留着）
    config.go            git config 的读与写：一次读回三层（system / global / local），写走上层给的 --global/--local
  diff/                  unified diff 解析
    slice.go             从完整 patch 里原样切出一段（按块暂存要用）
    range.go             按行范围现造一段补丁（上下文只取两侧真一样的行）
  explain/               提示词构建：提交信息、分支名、PR 审查、风险预扫（纯函数，不碰网络）
  llm/                   Anthropic + OpenAI 兼容接口的流式客户端
    failure.go           把供应商的错误翻成人话（说什么事 / 怎么办 / 原话留着）
  store/                 config / state 持久化
  filetree/              树的构建、摊平与模糊筛选（侧栏和文件列表共用）
```

> **线程约定**（详见 `app.go` 顶部）：只有主线程读写 app 的字段，后台 goroutine 只收值参数、结果一律走 `dispatch` 回主线程调度。
