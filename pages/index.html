ARCHITECTURE

摒弃 Web 封装，回归单一本地可执行文件

01

GPU 直接绘制通道

基于纯 Go 与 mygo 底层图形管线，直接调用系统原生 Metal / Direct3D 接口提交图元。没有 Chromium 的 DOM 解析和重排重绘，长达万行的提交历史与大型 Diff 在 60fps 下保持绝对平滑。

02

无彩色克制视觉规范

继承 Linear 经典的黑白两极（Achromatic）系统：深色下白键黑字，浅色下黑键白字。界面本身不使用多余杂色，将视网膜的注意力 100% 留给 Git 变动的语义增减与分支车道。

03

~35MB 极轻常驻开销

启动用时约 80 毫秒，待机内存占用约为 Electron 类工具的十分之一。即使开一整天、常驻后台处理庞大 Monorepo，也不会成为系统的资源黑洞。

WORKFLOW

把安全隐患与杂乱信息，拦截在提交之前

01

提交前自动风险审计 (Pre-flight Risk Scan)

当你审查别人提交的 Pull Request 或准备提交本地暂存时，Gloss 一键静态扫描暂存区中的代码变动，揪出意外带入的私钥、AWS/OpenAI 凭据、SQL 注入隐患和调试断点，按文件行号精准定位。

02

直连私有大模型 (Multi-LLM Native)

支持 Claude、OpenAI、DeepSeek 及本地 Ollama 实例。API Key 完全保留在本地。Gloss 深度理解代码差异块（Hunk），一键总结严谨的 Conventional Commits 格式，或根据单行需求生成规范分支名称。

03

已审查状态追踪与分块暂存 (Viewed Tracking)

大文件变更不再眼花缭乱。确认无误的文件一键折叠（Viewed），文件内容变动后自动重置状态。支持按变更块（Hunk）独立暂存与丢弃，全键盘操作不依赖鼠标。
