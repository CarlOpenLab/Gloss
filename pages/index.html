01REVIEW

Changes deserve to be read,
not just seen.

One change often touches code and static assets alike. Review a single file in focus, with word-level inline highlights, staging by hunk or by line, and native PNG, JPEG, GIF, WebP and BMP image compare. Every suspicious risk is flagged on the line it lives on — not buried in a dialog.

02TOPOLOGY

Forks and merges,
at a glance.

A hand-rolled Bézier lane algorithm, three built-in palettes and per-lane color overrides. “All branches” draws local, remote and tags into one graph, and the arrow keys walk the entire history.

03INTELLIGENCE

Commit messages,
from your own model.

Presets for Claude, DeepSeek, Kimi, Qwen and GLM ship in the box, and any OpenAI-compatible endpoint works too. Prompts, keys and repository context never leave your machine.

04TERMINAL & WORKSPACE

A fast built-in terminal,
code within reach.

Native multi-session terminals built on Ghostty, with custom monospace and Nerd fonts; pasting an image (⌘V) into AI CLIs like Claude Code forwards the clipboard sequence. The full workspace tree on the left tints by change state, and Git identity setup lives in one place.

05KEYBOARD

Hands on the keys.

⌘K opens the command palette, Space stages the current hunk, V marks a file reviewed, R starts a risk scan. Complete native macOS menu shortcuts — every press answers.

SpaceStage / unstage the current file or hunk
⌘KGlobal command palette
⌘↩Commit staged changes
VMark reviewed and collapse the file
[]Jump between diff hunks
RRun a risk scan
