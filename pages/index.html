01REVIEW

改动不止要看见，
要读得懂。

一次 PR 往往有几十个文件。提交信息、文件清单与逐行差异并排在同一屏；每一处可疑变更都被标在它所在的那一行，而不是藏进另一个窗口。

02TOPOLOGY

分叉与合并，
一眼到底。

自研贝塞尔车道算法，三条内置调色盘，支持逐车道配色。「All branches」把本地、远端与标签画进同一张图，方向键走完整个历史。

03INTELLIGENCE

提交信息，
用你自己的模型。

内置 Claude、DeepSeek、Kimi、Qwen 与 GLM 预设，也接受任意 OpenAI 兼容端点。提示词、密钥与仓库上下文只留在本机。

04KEYBOARD

手不离键。

⌘K 呼出命令面板，空格暂存当前 hunk，V 标记已读，R 发起风险扫描。完整 macOS 原生菜单快捷键，按下即有回应。

Space暂存 / 取消暂存当前文件或 hunk
⌘K全局命令面板
⌘↩提交已暂存的改动
V标记已读并折叠文件
[]在差异块之间跳转
R运行风险扫描

性能不是感觉，

同一台机器、同一个仓库的对照。没有 Chromium，没有 Node 运行时，也没有一个只在后台待命就吃掉半 GB 的进程。
